IP intel

Daily-refreshed ip2geo datasource for OpenSearch, tagging Tor, VPN, relay, proxy, cloud, bot, datacenter, scanner, botnet and spam networks.

  • manifest.json - ip2geo datasource endpoint
  • ip-intel.zip - CSV with network,category,provider

Last update: unknown

Use in OpenSearch:

PUT /_plugins/geospatial/ip2geo/datasource/ip-intel
{
  "endpoint": "https://sourced-data.kam193.eu/ip_intel/manifest.json",
  "update_interval_in_days": 1
}

IP intel uses the IP2Location LITE database for some of IP intelligence information.

Source: multiple data sources combined in kam193/assemblyline-data-cleanup. Data is refreshed once a day.
